# NEXORA — Autonomous Full-Stack Hyperlocal Marketplace

An AI-assisted hyperlocal marketplace and community platform connecting residents with trusted, verified local professionals.

## Highlights
- **Approved Visual Identity**: Deep forest green (`#0F382C`), soft neutral backgrounds (`#F8FAF8`), responsive cards, clean typography.
- **MERN Stack**: MongoDB, Express.js REST API, React 18, Node.js v24, Tailwind CSS.
- **Real Authentication**: Email/Password with bcrypt & JWT, Phone OTP verification cycle, Google & Apple OAuth buttons.
- **AI-Powered Smart Person Booking**: Natural language intent extraction, constraint resolution, multi-factor scoring, and transparent match explanations.
- **Complete Booking Engine**: Lifecycle transitions (`pending` -> `accepted` -> `in_progress` -> `completed` / `cancelled`), double-booking prevention, price snapshots.
- **Direct Payments & Commissions**: Cash & Direct UPI payment tracking with 10% platform commission calculation and admin reconciliation.
- **Verified Trust & Safety**: Provider government ID verification queue, reviews restricted to completed bookings, audit logs.
- **All Automated Tests Passing**: 23/23 tests pass with 0 errors.

## Quick Start
```bash
# Start backend & compiled frontend
cd server
npm start
# Visit http://localhost:5000 in your browser
```
